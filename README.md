# Grok Chat · 对话前端

一个受 Cue 简洁对话界面启发的聊天网页。左侧 AI 消息头像使用 Grok 角色动效，并随等待、思考、回复切换状态。

- 线上网页：https://wcccheryl.github.io/grok-icon-study/
- `index.html`：完整的单文件聊天页面。
- `animation.html`：原角色动效实验室。

支持消息发送、示例流式回复、停止生成、新建对话、本地历史记录、移动端布局、头像身形和配色设置。附件仅展示文件名，不上传或读取内容。

当前是前端交互演示，回复为本地预设示例，未连接 AI 模型服务。对话记录保存到当前浏览器的 localStorage。不会把聊天或附件发送到模型服务。

界面参考：https://justcue.ai/product 。这不是 Cue 官方产品，也不代表 Cue 的真实功能实现。

角色动效原项目：https://github.com/blessonism/grok-icon-study ，基于 b7e6cd4，保留来源署名。角色、商标、几何数据等归 xAI / 相应权利人所有。仅供学习参考，请勿商用或再分发。

本仓库仅包含前端网页，不包含解包脚本、提取的应用代码及其他参考文件。
